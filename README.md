# codealpha_tasks

---

## About This Repository

This repository contains the cybersecurity projects completed during my
CodeAlpha Cyber Security Internship.

The projects focus on practical cybersecurity concepts including:

- Network packet analysis
- Phishing awareness
- Secure code review
- Security vulnerabilities and remediation

---

## Projects

###  Task 1 — Basic Network Sniffer

A Python-based network sniffer developed using Scapy.

The project captures network packets and displays information such as:

- Source IP address
- Destination IP address
- Protocol
- Source and destination ports
- Packet length
- Payload
- Packet number
- Capture time

📁 Folder: `Task1_BasicNetworkSniffer/`

---

###  Task 2 — Phishing Awareness Training

A cybersecurity awareness training focused on phishing attacks and
social engineering.

The project covers:

- Phishing fundamentals
- Common types of phishing
- Phishing email indicators
- Fake websites
- Social engineering techniques
- Security best practices
- Real-world example
- Interactive quiz

📁 Folder: `Task2_PhishingAwareness/`

---

###  Task 3 — Secure Code Review

A security audit of a vulnerable Flask application.

The project identifies common vulnerabilities and demonstrates their
remediation.

The review covers:

- Hardcoded secret key
- SQL Injection
- Reflected XSS
- OS Command Injection
- Weak password hashing
- Sensitive information disclosure
- Debug mode and unsafe network binding

📁 Folder: `Task3_SecureCodeReview/`
